# GrammarSolution

Курсовая работа: библиотека и консольное приложение на C# (.NET 8) для работы с контекстно-свободными (КС) грамматиками. Программа пошагово показывает в консоли, как преобразуется грамматика: какие нетерминалы найдены, какие правила удалены и какие добавлены.

## Возможности

| Режим (`ActionType`)         | Что делает                                                                                                                                                                       | Результат                  |
|------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------|
| `MakeWords`                  | Перебирает слова языка в ширину. Для бесконечного языка работает до нажатия Enter.                                                                                              | консоль                    |
| `MakeWordsDetailed`          | То же, что `MakeWords`, но с полной цепочкой вывода каждого слова.                                                                                                                  | консоль                    |
| `SimplifyGrammar`            | Приводит грамматику к приведённой форме: устраняет ε-правила, цепные правила, непорождающие и недостижимые нетерминалы.                                                                    | консоль + `output.txt`     |
| `ConvertToChomskyNormalForm` | Приводит грамматику к нормальной форме Хомского: устраняет длинные правила, ε-правила, цепные правила, непорождающие и недостижимые нетерминалы, а затем правила с несколькими терминалами. | консоль + `output.txt`     |
| `FindShortestWords`          | Находит самые короткие слова языка (через нормальную форму Хомского) и выводит их в исходной грамматике.                                                                          | консоль + `output.txt`     |

## Структура решения

```
GrammarCourseWork.sln
├── GrammarLibrary/             # библиотека классов
│   ├── ContextFreeGrammar.cs   # КС-грамматика и все преобразования
│   ├── GrammarParser.cs        # разбор входного файла
│   ├── ILogger.cs              # интерфейс логирования шагов
│   └── ConsoleLogger.cs        # цветной вывод шагов в консоль
└── GrammarConsole/             # консольное приложение
    ├── Program.cs              # точка входа, выбор режима
    └── ActionType.cs           # перечисление режимов
```

## Сборка и запуск

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

1. Соберите решение:

   ```bash
   dotnet build
   ```

2. Выберите режим: поменяйте значение переменной `actionType` в `GrammarConsole/Program.cs`:

   ```csharp
   ActionType actionType = ActionType.FindShortestWords;
   ```

3. Положите файл `input.txt` с грамматикой в папку сборки `GrammarConsole/bin/Debug/net8.0/`. Программа ищет его рядом с исполняемым файлом, а при сборке он туда сам не копируется.

4. Запустите:

   ```bash
   dotnet run --project GrammarConsole
   ```

`output.txt` создаётся в текущей рабочей папке. При `dotnet run` это папка, из которой выполнена команда. При запуске из IDE обычно это папка сборки.

## Формат входного файла

```
# Пример грамматики
start: S
S -> aSb | AB   # рекурсия и конкатенация
A -> a | _      # _ обозначает ε
B -> b | c
```

- `start: S` задаёт начальный нетерминал. Он должен быть указан ровно один раз.
- `A -> α | β | ...` задаёт правила. Альтернативы разделяются `|`. Правила для одного нетерминала можно писать и на разных строках.
- `_` обозначает пустую цепочку ε.
- `#` начинает комментарий до конца строки. Пустые строки пропускаются.
- Каждый терминал и нетерминал — это ровно один символ. Пробелы допустимы только вокруг `->` и `|`. Внутри альтернативы (например, `a S b`) пробел вызовет ошибку разбора.
- **Нетерминалы** — заглавные латинские буквы `A`–`Z`, а также латинские буквы с диакритикой (`À`, `Á`, `Ā`, ...). Из этого списка программа сама берёт новые нетерминалы, когда они нужны при преобразованиях.
- **Терминалы** — строчные латинские буквы `a`–`z`, цифры `0`–`9` и знаки `` ! @ % ^ & * ( ) - = + [ ] { } \ ; : < . > / ? , ``.
- Символ `$` зарезервирован: если язык содержит ε, при устранении ε-правил добавляется новый начальный нетерминал `$ -> ε | S`.

## Пример

Для грамматики из примера выше режим `FindShortestWords` запишет в `output.txt`:

```
Самые короткие слова: b | c
Выводы:
S -> AB -> B -> b
S -> AB -> B -> c
```

Для грамматики `S -> aSb | ab` результат будет таким:

```
Самое короткое слово: ab
Вывод: S -> ab
```
